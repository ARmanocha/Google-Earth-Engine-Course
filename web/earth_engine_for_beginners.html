How to use the scripts

  1. Sign in to the Code EditorOpen code.earthengine.google.com. The setup guide shows how to register.
  2. Copy a scriptPick a lesson from the list and press Copy script.
  3. Paste, save, runIn the Scripts tab choose NEW → File, paste, save, then press Run.
  4. Read and tryRead the comments from top to bottom, then do the exercises at the end.

Reading the code

The code on this site is colour-coded so you can tell explanations from instructions, and your browser's work from Google's.

  • // noteA comment: the explanation of the line below it.
  • ee.ImageEarth Engine object. Runs on Google's servers.
  • MapCode Editor tools: Map, print, ui, Export.
  • 'text'Text, such as dataset IDs, band names and dates.
  • 4000A number.

When something goes wrong

Error messages appear in red in the Console. These are the ones beginners meet most often.

MessageUsual causeFix
… is not definedA typo in a variable name, or the variable is created further downCheck spelling and capital letters; create the variable before using it
Unexpected tokenA missing comma, bracket or quoteCount ( ) [ ] { } and check commas between items
Pattern 'B8' did not match any bandsThe band name is wrong for this dataset (Landsat uses SR_B5)Print the image and read its band names
Empty results or Error in mapThe filters removed every imagePrint .size() after each filter
Too many pixels in the regionThe area is too big for the chosen scaleAdd maxPixels: 1e13 or use a coarser scale
Computation timed outThe request is too heavy to show on screenUse an Export, a coarser scale or tileScale: 4
User memory limit exceededA very large calculationAdd tileScale: 4 (or 8, 16)
Asset not foundWrong asset path, or the asset is not sharedCopy the exact path from the Assets tab and check sharing
Export never startsThe task was created but not runOpen the Tasks tab and click RUN

Scripts are written for the Earth Engine Code Editor (JavaScript). If a script reports that a dataset cannot be found, look it up in the Earth Engine Data Catalog.

Field sites for the upload exercise

Ten example points around Mandi for lesson 06. Five are named places; the five marked to_check are for you to identify with the Inspector.

Make the file

  1. CopyPress Copy CSV above.
  2. SavePaste into a plain-text editor (Notepad, TextEdit in plain-text mode) and save as field_sites_mandi.csv.
  3. UploadIn the Code Editor: Assets → NEW → CSV file. Check that X is longitude and Y is latitude.
  4. Use itIn lesson 06, put in your project ID and set USE_MY_FIELD_SITES = true.
